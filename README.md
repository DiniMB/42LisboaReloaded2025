## 📋 Sobre o Projeto

A **Piscine Reloaded** é uma revisão dos conceitos fundamentais da C Piscine. É o primeiro projeto do Common Core e prepara-te para a **Libft**.

**Duração:** ~1 semana  
**Linguagem:** C e Shell  
**Avaliação:** Moulinette + 2 peer evaluations
